Lesson 1: Multiplication Review

Before we learn division, let's make sure your multiplication facts are solid — division uses them constantly. We'll go table by table, then mix it up with matching, missing numbers, and word problems.

What multiplication means

4 × 3 means 4 groups of 3. You can find the answer by adding 3 four times: 3 + 3 + 3 + 3 = 12. So 4 × 3 = 12.

Here it is as a picture — 4 groups, each with 3 stars:

Count the groups (4), count each group (3), then count every star (12). That's what × is doing.
