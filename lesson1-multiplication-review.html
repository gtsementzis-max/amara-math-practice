The Dragon Hatchery

Welcome to the Hatchery, Dragon Keeper! Before Mama Dragon can share her eggs between nests (that's division — Lesson 2), you need to count them fast: nests × eggs in each nest. We'll go table by table, then matching, missing numbers, and dragon adventures.

🥚 What multiplication means

4 × 3 means 4 nests with 3 eggs in each. You can find the answer by adding 3 four times: 3 + 3 + 3 + 3 = 12. So 4 × 3 = 12.

Here it is as a picture — 4 nests, each with 3 dragon eggs:

Count the nests (4), count each nest (3), then count every egg (12). That's what × is doing.
